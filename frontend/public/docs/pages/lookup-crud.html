Datos Maestros: Cobradores, Obras Sociales, Servicios y Tipos

Estas secciones permiten administrar los datos de referencia (lookups) que se usan en todo el sistema: Cobradores, Obras Sociales, Servicios Adicionales, Tipos de Grupo y Tipos de Plan.

💡 Nota: Todas estas secciones siguen el mismo patrón CRUD: ver listado, crear, editar, eliminar. Las instrucciones aplican a todas.

Acceso

Desde el Dashboard, menú izquierdo, sección "Gestión", verás:

  • Cobradores
  • Obras Sociales
  • Servicios Adicionales
  • Tipos de Grupo
  • Tipos de Plan

Pantalla Principal (Todas)

Cada sección tiene:

  • Tabla de listado: todos los elementos registrados
  • Búsqueda: filtrar por nombre o criterio
  • Botón "+ Nuevo": crear elemento nuevo
  • Acciones: editar y eliminar

Crear un Elemento

Pasos:

  1. Haz click en "+ Nuevo"
  2. Se abrirá un modal con un formulario
  3. Completa los campos requeridos
  4. Haz click en "Guardar"

Campos Típicos

  • Nombre: nombre del elemento (requerido)
  • Descripción: información adicional (opcional)
  • Estado: activo/inactivo (según la sección)

Editar un Elemento

Pasos:

  1. En la tabla, haz click en el botón "✎ Editar"
  2. Se abrirá el modal con los datos actuales
  3. Modifica los campos necesarios
  4. Haz click en "Guardar"

Eliminar un Elemento

Pasos:

  1. En la tabla, haz click en el botón "🗑 Eliminar"
  2. Se pedirá confirmación
  3. Confirma para eliminar
⚠️ Importante: Si un elemento está siendo usado (ej: una obra social en un plan), puede que no se pueda eliminar. El sistema lo indicará.

Secciones Específicas

Cobradores

Personal encargado de cobrar cuotas. Se asignan a planes para identificar quién es responsable del cobro.

Campo típico: Nombre del cobrador

Obras Sociales

Instituciones de salud/cobertura. Cada plan debe estar asociado a una obra social.

Campos típicos: Nombre de la obra social, código, contacto

Servicios Adicionales

Servicios extra que se pueden agregar a un plan (dentistas, oftalmólogos, psicólogos, etc.). Un plan puede tener múltiples servicios.

Campos típicos: Nombre del servicio, descripción

Tipos de Grupo

Categorías de grupos familiares (Individual, Matrimonio, Familia, etc.).

Campos típicos: Nombre del tipo, descripción

Tipos de Plan

Categorías de planes (Plan Básico, Plan Premium, Plan Completo, etc.). Cada plan debe tener un tipo.

Campos típicos: Nombre del tipo, descripción

Errores Frecuentes

Error Solución
"No se puede eliminar" El elemento está siendo usado. Revisa dónde se utiliza y actualiza.
"El nombre ya existe" Ya existe un elemento con ese nombre. Intenta con otro.
"Campo requerido" Completa todos los campos marcados con asterisco.

Mejores Prácticas

  • Mantén los datos maestros actualizados y sin duplicados
  • Antes de eliminar, verifica que no esté siendo usado
  • Usa nombres claros y consistentes
  • Ordena alfabéticamente si es posible para facilitar búsquedas
