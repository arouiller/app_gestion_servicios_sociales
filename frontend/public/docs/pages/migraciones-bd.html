Migraciones de Base de Datos

Migraciones BD es una funcionalidad ADMIN ONLY que permite aplicar cambios en la estructura de la base de datos de forma controlada. Esto incluye crear tablas, agregar columnas, modificar índices, etc.

¿Qué es una Migración?

Una migración es un conjunto de cambios controlados en la base de datos. Cada migración tiene:

  • Versión: número único (ej: 1.0.5, 1.0.6)
  • Descripción: qué cambios incluye
  • Script Upgrade: cómo aplicar los cambios
  • Script Downgrade: cómo revertir los cambios (si es posible)

Acceso

  1. Desde el Dashboard, menú izquierdo
  2. Sección "Administración" (solo si eres admin)
  3. Selecciona "Migraciones BD"
⚠️ Acceso Restringido: Solo administradores pueden acceder.

Pantalla Principal

Verás tres secciones:

1. Listado de Migraciones Disponibles

Muestra todas las migraciones que aún no han sido ejecutadas.

Ejecutar una Migración

Pasos:

  1. En el listado "Migraciones Disponibles", busca la migración que deseas ejecutar
  2. Haz click en el botón "Ejecutar"
  3. Se pedirá confirmación
  4. Lee la descripción de cambios y confirma
  5. El sistema aplicará la migración
  6. La migración aparecerá en el Historial como "Ejecutada"
⚠️ IMPORTANTE: Las migraciones son cambios permanentes en la BD. Asegúrate de:
  • Hacer backup de la BD antes de ejecutar (responsabilidad del admin del servidor)
  • Leer la descripción de cambios
  • Ejecutar en ambiente de testing primero si es posible
  • No interrumpir la ejecución mientras está en progreso

Revertir una Migración

Si necesitas deshacer una migración (rollback):

Pasos:

  1. En el Historial, busca la migración ejecutada
  2. Si hay botón "Revertir", haz click
  3. Se pedirá confirmación
  4. El sistema ejecutará el script de "downgrade"
  5. La migración aparecerá como "Revertida"
⚠️ Advertencia: No todas las migraciones pueden revertirse (ej: si eliminan datos). El sistema lo indicará.

Estadísticas

La pantalla también muestra estadísticas generales:

  • Total de migraciones disponibles
  • Total de migraciones ejecutadas
  • Versión actual del BD
  • Última migración ejecutada (fecha)

Errores Frecuentes

Error Causa Solución
"Error al ejecutar migración" Problema técnico durante la ejecución (sintaxis SQL, permisos, etc.) Revisa los logs del servidor. Contacta al administrador técnico.
"Migración ya ejecutada" Intentaste ejecutar una migración que ya estaba hecha La migración está en Historial. No necesita ejecutarse nuevamente.
"No se puede revertir esta migración" La migración no tiene script de downgrade o tiene restricciones Esta migración no puede deshacerse. Contacta al admin.

Preguntas Frecuentes

¿Qué pasa si falla una migración a mitad de ejecución?

El sistema intenta revertir automáticamente. Si no puede, la migración queda en estado "error" y debe investigarse manualmente. Contacta al administrador técnico.

¿Puedo ejecutar múltiples migraciones a la vez?

Se recomienda ejecutar una a la vez en orden secuencial. Esto asegura que no hay conflictos y es más fácil de auditar.

¿Con qué frecuencia hay nuevas migraciones?

Depende del desarrollo. Cuando se agrega nueva funcionalidad, es posible que haya nuevas migraciones. El sistema te notificará.

¿Puedo crear migraciones personalizadas?

Solo el administrador técnico del sistema puede crear nuevas migraciones. Contacta al desarrollador del sistema.

Mejores Prácticas

  • Ejecuta migraciones en horarios con baja actividad de usuarios
  • Siempre haz backup antes de migrar
  • Lee la descripción de cada migración
  • Ejecuta una a la vez, en orden
  • Documenta cualquier error que ocurra
  • Comunica a los usuarios sobre cambios que afecten funcionalidad
