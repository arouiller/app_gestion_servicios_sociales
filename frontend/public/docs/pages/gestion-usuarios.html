Gestión de Usuarios

Gestión de Usuarios es una funcionalidad ADMIN ONLY que permite crear usuarios, cambiar sus roles y resetear contraseñas.

Acceso

  1. Desde el Dashboard, menú izquierdo
  2. Sección "Administración" (solo visible si eres admin)
  3. Selecciona "Gestión de Usuarios"
⚠️ Acceso Restringido: Solo los administradores pueden ver esta sección.

Pantalla Principal

  • Tabla de usuarios: listado de todos los usuarios del sistema
  • Botón "+ Nuevo Usuario": crear usuario nuevo
  • Acciones: cambiar rol, resetear contraseña

Columnas de la Tabla

Columna Descripción
Email Correo del usuario (identificador único)
Nombre Nombre y apellido
Rol Admin o Usuario (permiso de acceso)
Acciones Cambiar rol, resetear contraseña

Crear un Nuevo Usuario

Pasos:

  1. Haz click en "+ Nuevo Usuario"
  2. Se abrirá un modal con un formulario
  3. Ingresa el email del nuevo usuario
  4. Haz click en "Crear"
💡 Nota: Al crear un usuario, solo se requiere el email. El sistema asigna automáticamente:
  • Rol: "Usuario" (no admin)
  • Contraseña: blanqueada (el usuario debe establecer la suya)
  • Nombre: "JOHN DOE" (temporal)

Flujo de Onboarding del Nuevo Usuario

  1. Recibe un email con el enlace de acceso
  2. Intenta acceder con su email
  3. Marca el checkbox "Tengo contraseña blanqueada"
  4. Es redirigido a formulario de establecer contraseña
  5. Establece una contraseña nueva (mínimo 8 caracteres, 1 mayús, 1 minús, 1 número)
  6. Accede al sistema normalmente

Cambiar el Rol de un Usuario

Pasos:

  1. En la tabla, busca el usuario
  2. Haz click en el botón "Cambiar Rol"
  3. Se abrirá un modal con opciones
  4. Selecciona el nuevo rol: Admin o Usuario
  5. Haz click en "Confirmar"

Diferencias de Roles

Funcionalidad Admin Usuario
Gestión de Planes ✅ Acceso completo ✅ Acceso completo
Búsqueda de Afiliados ✅ ✅
Generación de Recibos ✅ ✅
Datos Maestros (Cobradores, OS, etc.) ✅ ✅
Gestión de Usuarios ✅ SOLO ADMIN ❌
Migraciones BD ✅ SOLO ADMIN ❌
⚠️ Importante: Cambiar un usuario a Admin le da acceso a Gestión de Usuarios y Migraciones (operaciones delicadas). Hazlo solo con usuarios de confianza.

Resetear Contraseña

Si un usuario olvida su contraseña, puedes resetearla para que establezca una nueva.

Pasos:

  1. En la tabla, busca el usuario
  2. Haz click en el botón "🔑 Resetear Contraseña"
  3. Se pedirá confirmación
  4. La contraseña será blanqueada
  5. El usuario deberá seguir el flujo de login con "Tengo contraseña blanqueada"

Campos de Creación

Campo Requerido Descripción
Email Sí Correo electrónico del usuario (debe ser único)

Errores Frecuentes

Error Solución
"Email ya existe" Ya hay un usuario con ese email. Verifica que el email sea único.
"Email inválido" El email no tiene formato válido (ej: debe tener @).
"No puedes cambiar tu propio rol" No puedes downgradearte a ti mismo de admin. Otro admin debe hacerlo.

Preguntas Frecuentes

¿Qué pasa si hago admin a alguien por error?

Otro admin puede cambiar el rol nuevamente. No hay problema.

¿Puedo eliminar un usuario?

Actualmente no hay funcionalidad de "eliminar usuario". Los usuarios permanecen registrados. Si no deben acceder, cambia su rol o contacta al admin superior.

¿Cuánta contraseña es segura?

Se requiere: mínimo 8 caracteres, 1 mayúscula, 1 minúscula, 1 número. Ejemplos:

  • ✅ GestSocial2024
  • ✅ MiPassword123
  • ❌ password (sin mayúscula)
  • ❌ PASSWORD (sin minúscula)
